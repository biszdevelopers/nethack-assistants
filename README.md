# nethack-assistants

A collection of character prompts for AI assistants.

Each prompt defines a specific persona – pragmatic, witty, supportive, etc. – designed for hackathons, club mentoring, or general coding help bots.

## Usage

Copy the system prompt from any `.md` file into your AI’s system instructions (OpenAI, Claude, Ollama, etc.). The greeting and examples show expected behavior.
